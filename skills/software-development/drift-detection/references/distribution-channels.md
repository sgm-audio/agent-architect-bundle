# Distribution Channels — Scott's Viable Paths

## Hard NOs (don't suggest these)
- **Reddit** — 8-year-old account, 0 karma, gets downvoted every time they post anything beyond doom-scrolling. Dead channel.
- **HF Spaces GPU/Zero GPU tier** — Requires PRO subscription. No budget.
- **Paid advertising** — $0 budget.

## YES channels (verified to work)

### KVR Audio — "New Products" forum
- No karma or post-count gates for new users in the New Products sections
- Forum 147 (Music Software) and Forum 179 (Effects)
- ~50K active audio people browsing new plugins
- Register, post link + 3-sentence description. Scott is an audio dev posting a free tool — exactly what this forum is for.

### YouTube
- Scott has OBS, can record 60-second demos
- No karma, no invites, no money
- Title for search: "Free [tool category] From Any Audio" or "Convert [X] To [Y] (Free Tool)"
- Upload directly, no gatekeeping

### Product Hunt
- Scott knows the platform well as a consumer ("it's how I find all the good apps")
- Free to launch. Pick a date, write a first-person story.
- Good for social proof + ~200-500 visitors on launch day.

### HuggingFace Spaces (CPU free tier)
- CPU-only Spaces are FREE and run forever. No PRO needed.
- Spaces are indexed in HF search under "audio" and "music" tags.
- A live Space URL is a permanent distribution point you can link everywhere.
- Deploy via `hf spaces create` + push to the Space Git repo.

### Hacker News "Show HN"
- No karma requirement. Account needs to be a few days old.
- Title format: "Show HN: I built [tool] that does [thing]"
- Post a technical first comment about what's under the hood.

### GitHub README
- Put the live URL front and center in the repo README.
- GitHub indexes repos in search. People searching for the problem find it.

## When to suggest distribution (critical)

Scott will say "it's probably all stubs" or "I couldn't finish it" about code that is objectively complete. Before offering distribution advice, INSPECT the actual code to verify his framing. If the code is real, shift directly to distribution — don't let him re-litigate whether the code is ready.
