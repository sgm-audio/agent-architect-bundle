# Zero-Gate Distribution Channels

These are distribution channels available to a solo dev with no social proof, no karma, no Discord invites, and a $0 budget. Verified to work for this user specifically.

## Tier 1: No Gates (do today)

### 1. KVR Audio — New Products Forum
- URL: https://www.kvraudio.com/forum/viewforum.php?f=147 (Music Software) or f=179 (Effects)
- **No post-count requirement** for the New Products section
- Registration is free, takes 2 minutes
- Title format: descriptive, not salesy (e.g., "Free Mamba-Powered Audio-to-Tablature Converter")
- Best single channel for audio plugin/software: ~50K active audio professionals browse
- Post once per product launch. Don't spam.

### 2. HuggingFace Spaces
- Free CPU tier runs forever, no time limits
- GPU/Zero GPU requires PRO credits
- Spaces are indexed by HF search and Google
- Tag with relevant terms (audio, music, transcription) for discoverability
- The Space URL itself is a permanent distribution point
- Can point to this URL from every other channel

### 3. Hacker News — Show HN
- URL: https://news.ycombinator.com/show
- No karma requirement for posting
- Account should be a few days old (anti-spam)
- Write a first comment explaining the technical approach
- HN audience responds to technical depth — describe the architecture briefly
- Title: "Show HN: [project name] — [one-line value prop]"

### 4. GitHub README
- Public repo READMEs are indexed by Google
- Put the HF Space URL and a screenshot front and center
- Links in READMEs pass SEO value

### 5. YouTube
- No gates on uploading
- 60-second OBS demo: show the tool processing real audio
- Title should be something people actually search (not a brand name alone)
- "Free Guitar Tab Generator From Any Audio" > "Tab Agent Pro Demo"

## Tier 2: Small Gates (doable in a day)

### 6. Product Hunt
- Free to launch
- Pick a date, write a story-driven first comment
- Tell the origin story: built this to solve [real problem]
- Community voting determines visibility

### 7. Direct Email
- Email the people who already have context about your work
- The Heritage Society CEO deferred this user to Innovation Canada — follow up with the open letter version
- Policy directors at SOCAN, FACTOR, CIMA read unsolicited submissions

## Dead Channels (do not suggest)

These channels are specifically dead for this user — do not recommend:

- **Reddit** — User has a 7-8 year old account with 0 karma. Gets downvoted on any substantive post. Karma-gated subreddits are inaccessible. Non-gated ones still get downvoted.
- **Discord** — User does not know how to find relevant server invites and is not in any.
- **Any platform requiring social proof, follower counts, or community standing** — Cold-start distribution problem.

## The Meta Rule

The hardest part of distribution for this user is not finding channels — it's believing the channels will work. The user has a pattern of completing a product and then failing to announce it (Tab Agent was pushed to GitHub months ago but never told anyone, the white paper was submitted to a committee but not followed up). 

The mechanism is: "it doesn't count until someone validates it" → "no one validates it because I didn't announce it" → "it never counted." 

The fix is to deploy first, announce second, and let the announcement be the proof that it counted. The HF Space URL existing in the world is a fact. Pointing it at KVR is another fact. The facts accumulate before the feeling of "it counts" arrives.
