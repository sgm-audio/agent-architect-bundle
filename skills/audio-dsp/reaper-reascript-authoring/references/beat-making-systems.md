## Hip EDM Hybrid Template System

Template for blending hip-hop and EDM production in REAPER:

### Structure
- Intro → Build → Drop → Verse → Chorus → Bridge → Outro
- Each section has tempo-relative markers and time signature changes

### Sound Design
- Bass: 808 sub + mid-range aggressive layer
- Drums: Acoustic hip-hop kit + electronic EDM percussion
- Synths: Analog-style leads (hip-hop) + supersaw pads (EDM)
- FX: Buildups with automated HPF, reverb sends, risers

### Mix Strategy
- Sub-bass: Mono below 100 Hz, sidechain to kick
- Mids: Width from synths, center from vox/snare
- Highs: Air from open hats, shimmer from reverb tails
- Master: Gentle glue comp, limiter for competitive loudness
